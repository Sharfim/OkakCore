## О проекте

**Okak Core** — это ядро голосового ассистента, 
способного выполнять команды.

Написано на **Rust**. **Не зависит** от конкретных технологий 
(TTS, ASR, UI) — они подключаются как отдельные модули.

### Философия

- **Ядро** знает только логику: поиск команды, запуск, примитивы.
- **Команды** — это функции. Простые. Независимые.
- **Примитивы** — доступ к системе через traits.
- **Модули** (Vosk, TTS, Tauri) — снаружи. Ядро о них не знает.

### Что умеет

- Поиск команды по тексту (Левенштейн — опечатки, падежи).
- Запуск команд с доступом к примитивам.
- Тестируется без Vosk, без Tauri, без микрофона.
